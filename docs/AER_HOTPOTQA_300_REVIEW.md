# HotpotQA 300/1/1 改动 review

本次完成代码自查、真实本地数据校验和离线集成测试；未启动付费的 300 题 baseline。

## 修改范围

- 新增 HotpotQA 专用选题模块：固定公开特征、文本相似度、全局题面/ID 去重、类型均衡、可审计匹配。
- 通用 manifest 增加可选的 `holdout_reuse` 约束；旧清单默认允许复用，原有选题函数保留。
- 数据准备 CLI 默认改为 300 个当前任务、每题 1 个 similar / 1 个 regression、无额外 test。
  严格选择前做源数据结构校验；异常标注只排除并记录，不进行修补。
- 新增 300 题配置、900 题清单、数据检查报告；原四题配置和清单未修改。
- 新增可选 `--report-holdouts` 和独立报告模块，对每个任务初始/最终稳定版本补齐留出观察。
  该功能不改变 GEPA 搜索、路由、验收公式或提交行为；默认旧命令不增加模型调用。
- 汇总增加初始/最终成功率、状态转换、回归损失、明确的缺失数量和分母。

## 核验结果

1. **数据**：真实加载 300/300/300 道题，900 个 ID 和规范化题面均唯一；当前题 bridge/comparison 各 150。
   所有逐任务映射符合计数及公开特征匹配规则。源文件 SHA-256 全部通过。
2. **异常与可复现性**：90,447 道原始 train 题中排除 22 道越界证据引用；另有 9 个候选当前任务
   因没有可用相似匹配而跳过。全部原因写入清单。从固定源文件重新生成整份 300/1/1 清单，
   解析后的全部内容一致（将不同输出目录的源文件相对路径统一解析后比较）。
3. **数据边界**：匹配仅使用 ID、题面、type、level；测试改变答案/证据标签及打乱输入顺序不改变匹配。
   源完整性检查单独检查证据引用是否存在。GEPA 的内部任务范围仍限当前题。
4. **报告语义**：接受时复用已验收的初始/最终证据；拒绝时报告最终保留的初始版本，不误报被拒候选。
   无候选时执行缺失留出题，未变版本复用初始观察。新增调用计入用量，缓存命中计零新增消耗。
   已知评分可保留，即使用量不完整；缺失/错误评分明确计数，不从成功率分母中悄悄排除。
5. **兼容性**：旧四题数据版本仍为 `hotpotqa.distractor.8cdaa79966167d8f705f`，未因新增可选字段
   改变既有缓存身份。原生评分代码、路由器、GEPA 引擎、接受策略和单任务入口均未修改。
6. **测试**：89 项相关回归测试全部通过，覆盖 HotpotQA、新选题、批量报告、benchmark/GEPA/validation
   装配、缓存执行、配对验收、加权接受和 CLI。最后一次报告统计调整后，17 项选题与批量集成测试再次通过。
   本次没有重新跑全仓测试；以上是相关测试范围。

## 实验解释与运行限制

- 相似度是类型/问句/难度约束下的 TF-IDF 文本代理，不保证题目语义等价。规则和实际匹配样例可审阅。
- 每题只有一条回归观察，无法覆盖全部其他能力；两类留出题均参与验收，不是最终独立测试集。
- 同一初始版本没有被替换时，初始/最终留出表现使用同一观察，不能当作两次独立采样。
- 仍采用独立任务适应：300 个最终 Prompt 状态，不产生唯一通用 Prompt。
- 现有全局累计 Token/时间预算尚未强制执行；批量运行不支持断点续跑。实际消耗和已完成任务逐题保存。

运行命令、详细匹配标准与报告字段见 [AER_HOTPOTQA_300_BASELINE.md](AER_HOTPOTQA_300_BASELINE.md)。
